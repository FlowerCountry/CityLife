# CityLife Go

城市生活模拟游戏 - Go语言版本

## 简介

这是 CityLife 游戏的 Go 语言重写版本，使用 [Bubble Tea](https://github.com/charmbracelet/bubbletea) 作为终端 UI 框架。

## 功能

- 🏙️ **城市导航**：在市中心、超市、银行、医院之间移动
- 💰 **金钱系统**：钱包（面值追踪）和银行存款
- 🛒 **购物系统**：20+ 商品，支持购买和营养效果
- 🍎 **营养系统**：20+ 营养类型，影响生存和健康
- 🤒 **疾病系统**：6种疾病，触发/治愈状态机
- 🏥 **医疗系统**：看病、体检、购买药品
- 💾 **存档系统**：3个存档槽位，JSON格式

## 构建

```bash
# 下载依赖
make deps

# 构建
make build

# 运行
make run

# 或者直接
go build -o bin/citylife ./cmd/citylife
./bin/citylife
```

## 游戏玩法

### 位置和行动

| 位置 | 可用行动 |
|------|----------|
| 市中心 | 查看公告、地图、健康状态、存档/读档、查看钱包 |
| 超市 | 进入超市购物 |
| 超市内部 | 购买20+种食物和饮料 |
| 银行 | 存款、取款、查看余额 |
| 医院 | 看病、体检、购买药品、查看疾病状态 |

### 营养系统

- **核心属性**：饱腹感、饥渴、蛋白质、碳水化合物（直接影响生存）
- **微量元素**：钙、铁、锌、维生素A/B/C/D/E等（长期健康）
- **特殊属性**：幸福感、精神振奋（心理状态）

营养等级：
- 安全区 (50-100)
- 警告区 (20-50)
- 危险区 (0-20)
- 透支区 (-10到0)
- 濒死区 (<-10)

### 疾病系统

| 疾病 | 触发条件 | 严重程度 | 治疗费用 |
|------|----------|----------|----------|
| 感冒 | 维生素C不足 | 轻度 | 50元 |
| 贫血 | 铁不足 | 中度 | 200元 |
| 坏血病 | 维生素C严重缺乏 | 重度 | 500元 |
| 食物中毒 | 食用不新鲜食物 | 中度 | 100元 |
| 营养不良 | 蛋白质不足 | 中度 | 150元 |
| 抑郁症 | 幸福感长期过低 | 中度 | 300元 |

## 操作说明

- `↑`/`↓` 或 `j`/`k`: 选择菜单项
- `Enter` 或 `Space`: 确认选择
- `1-9`: 快速选择菜单项
- `Esc`: 返回/取消
- `q` 或 `Ctrl+C`: 退出游戏
